Visual Studio Code

Una herramienta para desarrollar aplicaciones y páginas web.

¿Qué es?

Visual Studio Code es un editor de código que permite trabajar con diferentes lenguajes de programación.

Información ampliada

Instalación

Se descarga desde la web oficial, code.visualstudio.com, y está disponible para Windows, macOS y Linux.

Ventajas

  • Es gratuito y funciona en los tres sistemas operativos principales.
  • Es ligero y arranca rápido, incluso en equipos modestos.
  • Reúne editor, terminal, depurador y Git en una sola ventana.

Extensiones

El Marketplace ofrece miles de extensiones. Para desarrollo web son habituales Live Server, Prettier y ESLint.
